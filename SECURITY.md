# Security policy

## Reporting a vulnerability

Please report security problems through GitHub private vulnerability reporting. Open the Security tab of this
repository, choose "Report a vulnerability", and describe the problem there. Don't open a public issue or pull
request for a security problem, because that makes the details visible before a fix is ready.

A useful report says which file or script is affected, which operating system and auditd version you used, and
the steps that reproduce the problem. Please don't include real hostnames, addresses, or credentials from your
systems.

## Supported versions

Only the latest `0.x` release receives security fixes. Earlier releases are not patched.
